# Agent guide

## What this is

Human × Time is a single-file web page: a hand-drawn canvas globe of 38,242 dated, located human events from Wikidata (71,860 BCE to 2026). It has two axes. Time runs along the bottom, and **coverage** (how many Wikipedia language editions carry the event, and which) runs up the right edge. It is the sibling of Earth × Time and shares that site's globe, build shape and gates. Vanilla JS, no framework, no runtime network. **Current state: working.** The build and both smoke tests pass, and the 3 August UX review is closed for this site. `README.md` explains every design choice and the known gaps; read it before you change behaviour.

## Commands (all verified from repo root)

```bash
python tools/build.py                          # ~90s. Packs, builds, smoke-tests. Expect: "16/16 pattern cases as expected",
                                               #   "events 38,242  categories 62  langs 32", then "124/124 checks passed" twice
                                               #   (index.html and artifact.html), exit 0, and no git diff
python tools/build.py --no-smoke               # build without the browser gate (never as the final check)
python tools/smoke_test.py                     # smoke-test ./index.html alone; --artifact for artifact.html; --headed to watch
python tools/pack_events.py                    # Expect: per-column byte table, then "round-trip: OK"
python tools/check_no_local_paths.py --self-test   # Expect: 16/16 pattern cases as expected
python tools/check_no_local_paths.py --all     # exit 0 = no home-directory path in any tracked file
python -m http.server 8000                     # optional; human-x-time.html also opens straight off disk
```

- The smoke test needs `playwright` with Chromium (installed on this machine). Without it, `build.py` prints "skipping smoke test" and still exits 0, so check that the `124/124` lines actually appear.
- Set `PYTHONUTF8=1` on Windows: event names carry every script.
- **Network, not run during verification** (free public APIs, slow, rewrite committed data; owner's call): `tools/fetch_events.py --per-cat 1800` (Wikidata SPARQL, rewrites `src/events.json`), `tools/fetch_languages.py` (rewrites `src/events.json` in place), `tools/fetch_coast.py`, `fetch_fonts.py`, `fetch_texture.py` (each rewrites one `assets/` file).

## Conventions and gotchas

- **Edit `src/`, never the built files.** `index.html`, `human-x-time.html` and `artifact.html` are generated by `tools/build.py` and committed (Pages serves `index.html`). Commit them together with the `src/` change that produced them.
- **One query path.** Every view reads `queryEvents()`. Do not add a second filter.
- **Class QIDs are resolved by name, never typed by hand** (that is how this project once called a star "Chicxulub"). The cache in `tools/classes.json` is the reviewable record.
- **Fetchers refuse partial writes.** A half-fetched asset must not replace the shipped one. Keep that property.
- **The pre-commit hook** (`.githooks/`, already armed here with `core.hooksPath`) rejects any staged absolute home-directory path. Never write one into a doc, test or commit, and never bypass it with `--no-verify`. Use placeholders such as `/home/you/...`. **On this Windows machine the hook fails every commit** with "python3 is too old": it tries `python3` first, and `python3` here is the Microsoft Store stub. Fix it by putting a real `python3` first on `PATH` for the commit (for example a one-line shim that execs `python`), or by turning off the `python3.exe` App execution alias. The hook still runs its check either way.
- Rendering paints from input handlers as well as `requestAnimationFrame`, because rAF does not fire in a hidden document. Do not "simplify" that away.
- No secrets. The Wikidata fetchers send a User-Agent with a contact address; that is intended.
- **Do not read into context**: `index.html`, `human-x-time.html`, `artifact.html` (~2 MB each), `src/events.json` (~5 MB; use `python -c` or `jq`), `assets/*.txt`, `preview.jpg`.

Load these with the Skill tool when the situation comes up; the user does not need to ask.

## Before you finish any task

1. `python tools/build.py` → `124/124 checks passed` for both `index.html` and `artifact.html`, exit 0. If you added smoke checks, the count goes up; update this file.
2. `git status --short` → if you changed only docs, nothing under `src/`, `assets/` or the three HTML files may have moved. If you changed `src/`, the three HTML files change with it.
3. `git diff --stat` → only files you meant to change.
